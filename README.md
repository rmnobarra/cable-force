# Cable Force ⚡️🎮

A competitive, 8-bit retro-styled "Quick-Time Event" (QTE) racing game built with Phaser 3 and Node.js.

## 🕹 The Game
Players compete in real-time to match arrow-key sequences generated by the server. The first player to reach 50 points (5 successful rounds) wins the match. 

### Features
- **Real-time Multiplayer:** Powered by Socket.io and Redis for synchronized state.
- **8-Bit Aesthetic:** 256x240 native resolution with pixel-perfect rendering.
- **QTE Mechanics:** Fast-paced input validation with frame-independent animations.
- **Anti-Cheat:** Server-side validation of human reaction limits (400ms threshold).
- **Scalable Architecture:** Designed for Kubernetes with sticky sessions and horizontal scaling.

## 🚀 Getting Started

### Prerequisites
- [Docker](https://www.docker.com/)
- [Docker Compose](https://docs.docker.com/compose/)

### Local Development
1. Clone the repository.
2. Run the orchestration:
   ```bash
   docker-compose up --build
   ```
3. Open your browser:
   - **Frontend:** `http://localhost:8080`
   - **Backend API/Socket:** `http://localhost:3000`

*Tip: Open two browser tabs to start a match against yourself!*

## 🛠 Tech Stack
- **Frontend:** Phaser 3 (Canvas), Socket.io-client.
- **Backend:** Node.js, Express, Socket.io.
- **State/PubSub:** Redis (with `@socket.io/redis-adapter`).
- **Infrastructure:** Docker, Kubernetes (Nginx Ingress).

---

## 📜 Development Rules (Internal)
- **Resolution:** Must maintain 256x240 (NES Standard).
- **Input:** Use the Arrow Keys for QTE sequences.
- **Sync:** All game-starting logic must use the `playerReady` handshake to ensure both clients have loaded the scene.
