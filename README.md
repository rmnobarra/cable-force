# Cable Force ⚡️🎮

A competitive, 8-bit retro-styled "Quick-Time Event" (QTE) racing game built with Phaser 3 and Node.js.

## 🕹 The Game
Players compete in real-time to match arrow-key sequences generated by the server. The first player to reach 50 points (5 successful rounds) wins the match. 

### Features
- **Real-time Multiplayer:** Powered by Socket.io and Redis for synchronized state.
- **8-Bit Aesthetic:** 256x240 native resolution with pixel-perfect rendering.
- **QTE Mechanics:** Fast-paced input validation with frame-independent animations.
- **Modern Infrastructure:** Uses Kubernetes **Gateway API** (Envoy Gateway) for robust routing.
- **Sticky Sessions:** Cookie-based consistent hashing for stable WebSocket connections.
- **Scalable Architecture:** Designed for horizontal scaling with Redis state synchronization.

## 🚀 Getting Started

### Local Development (Docker Compose)
1. Run the orchestration:
   ```bash
   docker-compose up --build
   ```
2. Open `http://localhost:8080`.

### Kubernetes Deployment (Kind)
1. Ensure you have `kind`, `kubectl`, and `helm` installed.
2. Run the automated setup script:
   ```bash
   ./infra/setup-gateway-api.sh
   ```
3. Open `http://cableforce.127.0.0.1.nip.io`.
